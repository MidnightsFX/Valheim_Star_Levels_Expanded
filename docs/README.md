# Star Level System documentation

The full configuration for each feature, with examples. For an overview of the mod, see the
[main README](https://github.com/MidnightsFX/Valheim_Star_Levels_Expanded/blob/master/StarLevelSystem/Package/README.md).

The YAML files are in `BepInEx/config/StarLevelSystem/`. Settings these pages call the main config are in
`BepInEx/config/MidnightsFX.StarLevelSystem.cfg`. Many of them can also be changed in game, with the Mod Config button.
